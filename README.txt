# xyro tools Wi-Fi Tools — offline phone app

## Install
1. Upload the contents of this folder to a static website that uses HTTPS (for example, GitHub Pages).
2. Open that HTTPS address on your phone while online.
3. Android: use the browser menu and choose **Install app** or **Add to Home screen**.
4. iPhone: open in Safari, tap **Share**, then **Add to Home Screen**.
5. Open the installed app once. The service worker caches the app so it can then work offline.

A one-time internet connection is needed to load and install the PWA. After its files have been cached, the app's calculator works offline.

This is a PWA package, not a native APK/IPA.
